# Closure-aware truck routing

The planning worker's `POST /route` accepts an optional `closures` list (up to ten). Each item has a unique `id` and `west`, `south`, `east`, `north` bounds in longitude/latitude degrees. Supported rectangles have positive area, do not cross the antimeridian and span at most 0.5 degrees per axis. These bounds are a declared operational closure, not an inferred live traffic report.

The adapter passes each rectangle as a Valhalla `exclude_polygons` ring while retaining the complete supplied truck profile. It independently checks every decoded geometry segment against every rectangle, including boundary contact and crossings between samples. A required stop inside a closure, missing geometry, routing failure or returned crossing produces an explicit error; there is no car-route/straight-line fallback or silent relaxation. The response preserves closure bounds, profile, geometry, timing, toll flags and routing warnings.

Valhalla documents polygon exclusions and summary toll flags in its [official route API reference](https://valhalla.github.io/valhalla/api/route/api-reference/#other-request-options), accessed September 11, 2026. Documentation alone does not prove a deployed engine honored an exclusion, hence RoadStar's returned-segment check. Rectangles conservatively exclude all roads/levels within their bounds; this first adapter does not model lane-specific or grade-separated closures.

## Verified evidence and remaining work

`docs/evidence/closure-routing-2026-09-11.json` retains the synthetic request, closure, complete baseline/alternate geometry and hashes. Against the existing Ontario Valhalla VM, the ordinary Milton–London request was 138.882 km / 5870.869 modeled seconds. A mid-route closure produced a distinct 156.234 km / 6936.824-second route; all returned segments passed the independent exclusion test. The alternate has a toll segment, which must remain visible in later approval UI. The original truck dimensions, total weight, axle load and hazmat flag were unchanged. Closing the origin terminal explicitly failed, including through the real local worker HTTP endpoint (503).

27 optimizer/simulator tests passed. Mock-router tests intentionally ignore the polygon and confirm RoadStar refuses the crossing geometry. Boundary/tangent cases, positive bounds, a safe route and a closed required stop are tested. Use the `.roadstar` pyenv/Poetry environment and `VALHALLA_URL=http://127.0.0.1:48002 python scripts/verify-closure-routing.py` from the project root to reproduce the real-router comparison.
